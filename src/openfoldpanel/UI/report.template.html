轨道

序列与理化轨道

A 查询序列 表示目标序列在当前位置的残基字母单元格。
A 完全匹配 表示该位点残基与查询序列残基完全相同。
S 相似替换 表示该位点发生了保守替换，残基性质相近但不完全相同。
可及性 深蓝表示埋藏/隐藏，浅蓝表示暴露，用于反映残基表面可接近程度。
疏水性 橙色表示疏水，蓝色表示亲水，体现残基局部理化性质分布。

置信度轨道

很高 pLDDT ≥ 90，说明该区域结构预测可信度很高。
可信 70 ≤ pLDDT < 90，说明该区域预测整体较可靠。
偏低 50 ≤ pLDDT < 70，说明该区域预测可信度有限，需要谨慎解释。
很低 pLDDT < 50，说明该区域结构不稳定或预测不可靠。
